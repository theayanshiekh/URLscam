Backend API Endpoints

Integrate these JSON endpoints directly into your frontend, browser extensions, or security gateways.

1. Check Single URL

curl -X POST "http://localhost:5000/api/v1/check-url" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/verify-login", "include_features": true}'

2. Check Batch URLs

curl -X POST "http://localhost:5000/api/v1/check-urls" \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://google.com", "http://192.168.1.1/pay"]}'

3. Submit False Positive / Retraining Feedback

curl -X POST "http://localhost:5000/api/v1/reports" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://newsletter-link.com", "reported_as": "FALSE_POSITIVE"}'
